# 預先登記:錯殺回檔「路徑 B(淺回檔強動能)」的回測(2026-11-15 登記)

本文件在建立回測、看到任何結果之前寫下;登記後不得依結果修改方法或參數。若需修改,另開新版本並保留本版。

## 背景
錯殺回檔(GAS `Dislocation.js`)有兩條收錄路徑:
- **路徑 A**:自近一年最高收盤回檔 20–50%、站上 120 日均線、營收與毛利率年增 > 0、成交量門檻;
- **路徑 B**:回檔 < 20% 但動能強(條件見 `Dislocation.js` `evaluateDislocation`)。2026-08-13 依觀察加入,沒有回測。

## 問題
路徑 B 收錄的股票,在收錄後是否比同日股票池平均、或同日路徑 A 收錄的股票表現更好或更差。

## 資料與時點(避免前視偏差)
- 價格:還原價(含除權息);股票池為當日上市櫃普通股,以「前 60 個交易日平均成交值」排名(與急跌反轉回測同定義),只用當時資料。
- 月營收:每月 10 日(法定期限)後才可用;季財報:法定申報期限後才可用。
- 只用「今天仍上市」的股票有倖存者偏差,報告需註明。

## 方法
1. 期間 2019-01 至最近一個完整月;每月第一個交易日依當時可得資料執行兩條路徑的條件(參數用 `Dislocation.js` 2026-11-15 版本,不調整)。
2. 持有 20 個交易日;報酬扣來回成本 0.585%(與急跌反轉回測相同)。
3. 超額報酬:(a) − 同日股票池平均;(b) Phase 3 式:− 同日池內隨機抽與該路徑同檔數、持有相同天數。
4. 以訊號日期為群組 bootstrap 2,000 次,取 95% 信賴區間;2019–2023 為樣本內、2024 起為樣本外,只看一次樣本外。

## 判定(登記)
- 路徑 B 的樣本外超額 (b) 信賴區間下限 > 0 → 保留;上限 < 0 → 建議移除;含 0 → 頁面標「未經驗證」,保留與否由使用者決定。
- 路徑 A 同樣回報,但不因本回測改動路徑 A。

## 實作細節(2026-11-22 補記,寫於任何回測結果產生之前;不改變上方方法)
- 程式:`disloc_backtest.py`(v2026-11-22-disloc-bt),逐行移植 Dislocation.js 2026-11-15 版各關條件,含「基本面強度排序取前 120 檔精算」(MAX_CANDIDATES)。
- 股票池大小:本文件未寫明 → 採急跌反轉 Phase 3 的設定,前 200 名。
- (b) 隨機對照:每個訊號日、每條路徑,從同日股票池(排除該路徑已收錄者)以固定種子 20261115 抽一次,檔數 = 該路徑當日收錄檔數。
- 時點:月營收 11 日起才用上個月;季財報 / 現金流量以法定期限(Q1 5/15、Q2 8/14、Q3 11/14、Q4 隔年 3/31)後才用;
  GAS 的 FinMind 抓取期間(股價 400、月營收 500、財報 900、現金流量 950 日曆天)照樣模擬。
- 階段1 的 MOPS 當季快照以「最新已過期限的季別」近似;實際在申報期間會缺部分公司(見 Dislocation.js 檔頭),回測會略多收。
- 價格:yfinance 還原價;成交量張數 = 股數 ÷ 1000;階段 3.5 的當日量值粗篩用未還原收盤。
- 冒煙測試只印各關淘汰數與收錄檔數,不算報酬;正式回測一次跑完,樣本外結果只看這一次。
